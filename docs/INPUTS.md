# Input glossary

Every controller input a minigame can ask for, what it senses on the phone, and what the game receives. **Used by** links to the ideas in [MINIGAMES.md](MINIGAMES.md), so the inputs that many games need stand out.

Names are the supported `WidgetType` values in [the controls API](../src/client/controls/api.ts). Touch views and motion presentation belong to [controls](../src/client/controls/README.md); motion metadata and processors are registered separately from React UI. Try touch controls and layouts at `/?role=gallery`. The usage links below are game ideas and historical examples; Neon Harvest and Whack-a-Mole are the production games.

The unused `slider`, `dial`, `text` and `draw-canvas` widgets are retired. Layout imports, validation and resolution reject them; replace obsolete items with supported touch controls.

## Motion

These need motion permission on the phone (the **Enable motion** button). After capabilities and touch fallbacks resolve, a controller may have only one action using `pointer` or `tilt`: both mixed and repeated sensor types conflict because the binary frame carries one motion vector. Unused layout toggles do not count. Independent touch vectors remain supported. Shake and chop each consume a press slot, with at most four press actions in the resolved configuration. Conflicts produce a configuration error; the resolver never silently disables an action or changes its fallback to hide them.

| Input     | Senses                                                                                                            | Game receives                                                                                                                                                                                                                                                                                                                                                                                                | Used by                                                                                                                                     |
| --------- | ----------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------- |
| `pointer` | Rotation (gyro), phone held like a remote                                                                         | A position on the screen (0–1). Moves like a mouse: turn speed moves the cursor, quick flicks go further. Adjustable sensitivity; push past an edge or Recenter to re-center. A game may set `motion.bounds` to keep it inside its play field. The cursor stays tied to where the phone really points: compass and gravity win back drift during the player's own motion. A game may set `motion: { anchor: false }` to opt out | [Latency Lab](MINIGAMES.md), [Target Practice](MINIGAMES.md), [Darts](MINIGAMES.md), [Whack-a-Mole](MINIGAMES.md)                           |
| `tilt`    | Which way is down (gravity)                                                                                       | Left–right and forward–back tilt from −1 to 1; full scale at about 38° of tilt                                                                                                                                                                                                                                                                                                                               | [Tilt Rally](MINIGAMES.md), [Don't Spill the Milk](MINIGAMES.md), [Bowling](MINIGAMES.md), [Golf](MINIGAMES.md), [Kart Racer](MINIGAMES.md) |
| `shake`   | A hard, sudden movement in any direction                                                                          | A single event when acceleration passes about 1.8 g, at most once every 0.6 s; no direction                                                                                                                                                                                                                                                                                                                  |                                                                                                                                             |
| `chop`    | A sharp swing (gyro spin or acceleration jolt) while the player holds the on-screen button, which locks their aim | One press per swing, with strength 0–1 and the aim the big screen showed as the button was pressed; repeated swings each count; aiming resumes from the locked point the moment the button is let go, and the swing and its rebound never move it. Screens see the button held while the aim is locked                                                                                                       | [Whack-a-Mole](MINIGAMES.md)                                                                                                                |
| `jolt` | Sudden movement (acceleration) and rotation (gyro) | A timestamped impulse with strength 0–1: translation left/right/up/down/forward/back, or rotation around x/y/z with sign −1/+1. Requires acceleration and gyro access; a required jolt has no button substitute. | Registered extension proof; no production game uses it yet. |

Jolt settings use `InputRequirement.motion`. Device Y is inverted into controller Y; rotation is applied around controller Z. Missing linear acceleration falls back to orientation-based gravity compensation. Trigger/rearm thresholds, a calm window and a refractory period suppress repeat impulses. Synthetic traces and production ingress establish the contract; physical tuning remains unverified.
