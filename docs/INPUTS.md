# Input glossary

Every controller input a minigame can ask for, what it senses on the phone, and what the game receives. **Used by** links to the ideas in [MINIGAMES.md](MINIGAMES.md), so the inputs that many games need stand out.

Names are the `WidgetType` values in [src/core/types.ts](../src/core/types.ts). Inputs marked **(library)** come from the controls library in [src/controls](../src/controls/README.md). Try them at `/?role=gallery`. The rest are legacy widgets in [src/client/Widgets.tsx](../src/client/Widgets.tsx) and, for motion, [src/client/runtime.ts](../src/client/runtime.ts), waiting to be ported.

## Touch

| Input                  | Senses                                                     | Game receives                                                                                             | Used by                                                                                                                                                                                        |
| ---------------------- | ---------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `button` (library)     | A tap or press and hold                                    | Timestamped press / release edges                                                                         | [Latency Lab](MINIGAMES.md), [Target Practice](MINIGAMES.md), [Kart Racer](MINIGAMES.md), [Brawl](MINIGAMES.md), [Jam Session](MINIGAMES.md), [Bomb Squad](MINIGAMES.md)                       |
| `dpad` (library)       | A thumb on one of 4 (or 8) directions; slides between them | Direction `{x, y}` of −1, 0 or 1; `{0, 0}` on release                                                     | [Showdown Chop](MINIGAMES.md), [Brawl](MINIGAMES.md), [Jam Session](MINIGAMES.md)                                                                                                              |
| `stick` (library)      | A thumb dragged from wherever it lands                     | Direction `{x, y}` inside the unit circle, with a dead zone; `{0, 0}` on release                          | Fallback in [Latency Lab](MINIGAMES.md), [Tilt Rally](MINIGAMES.md), [Kart Racer](MINIGAMES.md), [Brawl](MINIGAMES.md)                                                                         |
| `swipe-pad` (library)  | A quick swipe across the pad                               | On lift-off: `{dir, x, y, distance, velocity}`, then a press edge (ignored if very short)                 | [Tilt Rally](MINIGAMES.md), [Basketball](MINIGAMES.md), [Kart Racer](MINIGAMES.md), [Chop Shop](MINIGAMES.md), [Saber Slash](MINIGAMES.md), [Jam Session](MINIGAMES.md), [Darts](MINIGAMES.md) |
| `draw-canvas`          | A finger drawing                                           | Position (0–1) and pressure while the finger moves                                                        | [Shape Flash](MINIGAMES.md)                                                                                                                                                                    |
| `slider`               | A slider thumb dragged                                     | A value from 0 to 1                                                                                       |                                                                                                                                                                                                |
| `dial`                 | A finger circling the widget                               | Total angle turned, in radians; keeps counting past one full turn                                         | [Bomb Squad](MINIGAMES.md)                                                                                                                                                                     |
| `hold-meter` (library) | How long a finger stays down                               | `{charge 0–1}` while held; on release `{charge, released: true}` and a press edge. Full in 1 s by default |                                                                                                                                                                                                |
| `text`                 | Typing and pressing Send                                   | The text, up to 120 characters                                                                            | [Bomb Squad](MINIGAMES.md)                                                                                                                                                                     |

## Motion

These need motion permission on the phone (the **Enable motion** button).

| Input     | Senses                                    | Game receives                                                                                                                                                                | Used by                                                                                                                                     |
| --------- | ----------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| `pointer` | Rotation (gyro), phone held like a remote | A position on the screen (0–1). Moves like a mouse: turn speed moves the cursor, quick flicks go further. Adjustable sensitivity; push past an edge or Recenter to re-center | [Latency Lab](MINIGAMES.md), [Target Practice](MINIGAMES.md), [Darts](MINIGAMES.md)                                                         |
| `tilt`    | Which way is down (gravity)               | Left–right and forward–back tilt from −1 to 1; full scale at about 38° of tilt                                                                                               | [Tilt Rally](MINIGAMES.md), [Don't Spill the Milk](MINIGAMES.md), [Bowling](MINIGAMES.md), [Golf](MINIGAMES.md), [Kart Racer](MINIGAMES.md) |
| `shake`   | A hard, sudden movement in any direction  | A single event when acceleration passes about 1.8 g, at most once every 0.6 s; no direction                                                                                  |                                                                                                                                             |

## Needed (not built)

| Input  | Senses                                             | Game receives                                                       | Used by                                                                                                                                       |
| ------ | -------------------------------------------------- | ------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| `jolt` | Sudden movement (acceleration) and rotation (gyro) | Which way the phone moved sharply (up, down, left, right) or turned | [Don't Spill the Milk](MINIGAMES.md), [Bowling](MINIGAMES.md), [Golf](MINIGAMES.md), [Chop Shop](MINIGAMES.md), [Showdown Chop](MINIGAMES.md) |
