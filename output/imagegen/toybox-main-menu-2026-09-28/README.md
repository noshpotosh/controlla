# Toybox main-menu concepts

Restyled versions: [these same three layouts in the newer faceted toy style](../toybox-faceted-remakes-2026-09-28/README.md).

Follow-up: [three further toy-world explorations](../toybox-main-menu-explorations-2026-09-28/README.md) try a pop-up playset, display window, and wooden train station.

Three additional main-menu mockups following the user's newer wooden Toybox game-screen reference. THE TOYBOX is a working title taken from that reference; the application has not been renamed.

| Concept | Image | Design intent |
| --- | --- | --- |
| Open Toybox | [04-open-toybox.png](04-open-toybox.png) | A central toy chest with two side-by-side actions inset into its front. |
| Welcome Pegboard | [05-welcome-pegboard.png](05-welcome-pegboard.png) | A wooden activity-board easel with stacked cream action plaques, closest to the gameplay reference's material language. |
| Toy Parade | [06-toy-parade.png](06-toy-parade.png) | A calmer asymmetric menu with actions on the left and a group of animal toys on the right. |

Shared direction: warm wood, coral and sage-teal painted trim, cream plaques, navy lettering, blue paneled room, and small lion/puppy/frog/bunny toy mascots. Create Room and Join Room are the primary actions. How to Play and the phone-controller helper are secondary. Active-round status, rankings, and game-selection controls are omitted from the entrance screen.

Created with the built-in image generation tool, using the supplied game screenshot as an edit target to redesign its layout. The complete [prompts](prompts.md) preserve the requested visual invariants and each composition. These are raster concept images; no UI implementation or interaction behavior was changed.

Validation: all three PNGs are 1672 × 941 pixels (approximately 16:9); their PNG signatures and dimensions were checked. Every image was visually inspected for the primary labels, How to Play, phone-controller helper, settings icon, and the absence of active gameplay status. Application tests were not needed or run for these image-only concepts. Actual device readability and accessible interactive states remain implementation considerations.

Recommended direction: Toy Parade for the clearest menu composition and prominent character personality; Welcome Pegboard for the closest visual continuity with the supplied game-selection screen.
