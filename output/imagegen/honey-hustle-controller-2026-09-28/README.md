# Honey Hustle controller mockups

Generated 2026-09-28 with the built-in imagegen tool. These are visual concepts, not changes to the controller implementation.

Reference: the user's supplied Honey Hustle garden-game image.

- [Honey disc](01-honey-disc.png)
- [Honeycomb](02-honeycomb.png)
- [Garden pad](03-garden-pad.png)

All variants use phone motion to aim, a dominant Pulse button, and a separate large Recenter button. Recenter sets neutral aim from the phone's current comfortable holding position. Suggested implementation: keep Recenter available during Pulse cooldown; preserve button dimensions between states. Tap sizes in the prompts are design targets, not measurements guaranteed by the generated raster images.
