# Bee rebrand mockups

Generated on 2026-09-28 using the built-in imagegen tool, with the supplied garden-arena image as a visual reference.

These are proposed visual directions and working names for Neon Harvest, not changes to the live game.

- [Bumble Rush](01-bumble-rush.png): closest to the reference; vivid greens, chunky wooden UI, energetic bee characters. Preferred name because it combines a cute bee identity with the pace of the collection game.
- [Honey Hustle](02-honey-hustle.png): honey-gold wood, amber light, and honeycomb details.
- [Bloom & Buzz](03-bloom-and-buzz.png): floral border, lighter wood, softer garden finish.

All three show four striped bees with colored scarves and trails, nectar/dew pickups, thorny mine hazards, a pollen pulse, wave/time counters, and player score cards. Four players are shown for comparison with the supplied reference; the existing game supports 1–8.
